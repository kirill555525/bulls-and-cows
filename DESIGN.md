# DESIGN.md

## 1. Структуры данных и алгоритмы

Состояние игры хранится в объекте `GameState`: настройки, секрет, история попыток, статус и время начала/завершения. Объект объединяет данные одного раунда. Типы `Readonly` защищают его поля от изменений на уровне TypeScript.

Секрет и попытки представлены строками, чтобы сохранять ведущие нули. История — массив объектов `{ guess, bulls, cows }`, сохраняющий порядок попыток. В `submitGuess` новая запись добавляется через `[...state.history, entry]`, а состояние создаётся через spread. Прежнее состояние и его история не изменяются.

**`evaluateGuess`** приводит строки к нижнему регистру и создаёт `Set` цифр секрета. Затем `reduce` проходит по попытке: совпадение цифры и позиции добавляет быка; иначе наличие цифры в секрете добавляет корову. Одна цифра не учитывается дважды.

**`countPossibleSecrets`** рекурсивно считает перестановки без повторений: `P(b, n) = b * P(b - 1, n - 1)`, базовый случай — `P(b, 0) = 1`. Ведущий ноль разрешён, поэтому для первой позиции доступны все цифры. Результаты сохраняются в `Map` с ключом `base:length`; повторный вызов возвращает значение из кеша.

## 2. Сложность

`n` — длина секрета или попытки, `b` — размер алфавита. Доступ к `Set` и `Map` оценивается в среднем как `O(1)`.

| Функция                | Время                                         | Обоснование                                                                                                        |
| ---------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `generateSecret`       | `O(n * b)`                                    | На каждом из `n` шагов `filter` создаёт новый массив оставшихся цифр, просматривая до `b` элементов.               |
| `evaluateGuess`        | `O(n)`                                        | Создание множества цифр секрета и один проход по попытке через `reduce`.                                           |
| `isValidGuess`         | `O(n * b)`; при ограничении `b ≤ 16` — `O(n)` | Проверяются символы и уникальность через `Set`. Для каждого символа `alphabet.includes` просматривает до `b` цифр. |
| `countPossibleSecrets` | Первый расчёт — `O(n)`, повторный — `O(1)`    | Рекурсия уменьшает длину на каждом шаге; готовый результат берётся из кеша.                                        |

## 3. Принципы чистого кода

- **Разделение ответственности:** `evaluateGuess` в `src/core/evaluate.ts` сравнивает строки; `loadScores` и `saveScores` в `src/services/storage.ts` работают с хранилищем; `src/ui/app.ts` обрабатывает события интерфейса.
- **Отсутствие дублирования:** `createDigitValidator` из `src/core/digits.ts` используется и в `isValidGuess` (`src/core/validation.ts`), и при фильтрации ввода (`src/ui/app.ts`).
- **Явные зависимости:** `generateSecret` в `src/core/secret.ts` принимает источник случайности параметром, а `createGame` и `submitGuess` в `src/core/game.ts` получают время через аргументы. Это позволяет писать предсказуемые тесты.
- **Ранние возвраты:** `submitGuess` в `src/core/game.ts` сразу отклоняет завершённый раунд, неверный ввод и повтор попытки, уменьшая вложенность условий.
